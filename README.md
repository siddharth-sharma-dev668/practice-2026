## The weekly loop

1. **Monday** — say `start week N` in chat
2. **Weekdays** — study brief + exercises + DSA set (~1.5–2h/day)
3. **Weekend** — build the project piece, take the week's quiz on the platform
4. **Sunday** — say `grade week N` → I review everything and score you

## Commands (say these in chat)

`start week N` · `grade week N` · `quiz me on <topic>` · `explain <topic>` · `dsa` · `mock interview <role>` · `review my resume` · `status` · `test out of week N`
